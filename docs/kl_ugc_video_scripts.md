### KL UGC動画の共通ルール（医療広告ガイドライン＋KLレギュレーション）
1. 話し手は **これから検討する人**、または **スタッフ・歯科衛生士**。「利用者の体験談」にはしない
2. 治療後の感想・効果・痛みの有無・満足度は一切話さない（「綺麗になった」「痛くなかった」「後戻りしない」はNG）
3. ビフォーアフター画像は使わない（使う場合は治療内容・費用・リスクの詳細説明が必須になるため、初回テストでは避ける）
4. 「安い」「お得」「総額」「無料」を強調しない → 「リーズナブル」「お手頃」「目安費用」を使う
5. 他ブランドとの比較はしない。ワイヤーとの比較は治療範囲を明記し、ワイヤーを貶めない
6. 「No.1」「トップクラス」は使わない
7. 必須の注記（最後の画面で常に表示）：
   - 目安費用9.9万円〜49.5万円
   - ※掲載している料金はすべて税込価格です。
   - ※別途、初回検診料、再診料、リテーナー費用がかかります。
   - ※症例により適応できない場合があります（診断が必要）【要確認：KL指定の文言】

### 共通本編の骨組み（OMT式に冒頭だけ差し替える）
1. **冒頭フック（0〜3秒）**：呼びかけ・独り言・クイズ
2. **共感（3〜10秒）**：「ずっと気になってた／でも矯正って高いし長いし」
3. **気づき（10〜25秒）**：前歯など気になる部分だけ治療する考え方（＝KLの独自性）
4. **ハードル除去（25〜40秒）**：初回に何をするか／目安費用／院の場所
5. **CTA（40秒〜）**：「まずは自分が対象か確認するところから」＋注記

### 冒頭フックの差し替え案（各本で3〜4本ずつABテスト）
- U1：①「前歯のここ、ずっと気になってたんだよね」②「笑うとき口元隠すの、もうやめたくて」③「矯正って全部やらなきゃだと思ってた」④「（地域名）で前歯だけ矯正できるとこ探してた人へ」
- U2：①「前歯気になってる人ちょっと聞いて」②「矯正って100万とかすると思ってない？」③「前歯のズレ、放置してる人いる？」
